# 食事栄養トラッカー

> このリポジトリには他にもアプリがあります: [`study-tracker/`](./study-tracker) — Googleカレンダーと連携した学習進捗管理アプリ。

食事の写真を撮ると、Claude(Anthropic API)がその写真から栄養素を推定し、
あなたの年齢・性別・体重などから計算した「1日に必要な栄養量」と比較して、
残り必要な栄養素や食べ方のアドバイスを表示するアプリです。

- データはすべてこの端末のブラウザ内(localStorage)に保存され、外部には送信されません
  (写真解析のときだけ、写真とAPIキーがAnthropicのAPIに送信されます)。
- サーバーは不要です。静的なHTML/CSS/JavaScriptだけで動きます。
- 宅配弁当や社食アプリの「成分表(目安)」のような、栄養成分がすでに印刷・表示されている
  写真(パッケージやアプリ画面のスクリーンショットなど)を撮った場合は、AIが写真から
  その数値をそのまま読み取って使います(「成分表示を読み取りました」と表示されます)。
  数値の記載がない場合は、これまで通り写真から見た目で推定します。

## 1. Anthropic APIキーの準備

1. https://console.anthropic.com にアクセスし、アカウントを作成/ログイン
2. 「API Keys」からキーを発行(`sk-ant-...`)
3. 少額のクレジットを追加(写真1枚の解析はごく小さなコストです)

アプリの初回設定画面、または「設定」タブでこのキーを入力してください。
キーはこの端末のブラウザ内にのみ保存されます。

## 2. 使い方(まずは自分のMacで試す)

`index.html` をダブルクリックしてブラウザで開くだけでも動作しますが、
サービスワーカー(オフライン対応)を有効にするには簡易サーバー経由で開くのがおすすめです。

ターミナルでこのフォルダに移動して:

```bash
cd nutrition-app
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## 3. スマホのホーム画面に追加したい場合

このアプリをiPhoneのホーム画面に追加してアプリのように使うには、
どこかインターネット上のサーバーに置いて `https://` でアクセスできるようにする必要があります
(GitHub Pages、Vercel、Netlifyなど無料のホスティングサービスが使えます)。

ホスティング先が決まったら教えてください。デプロイ作業もお手伝いします。
Mac上でローカルサーバーとして動かす場合も、Macとスマホが同じWi-Fiに繋がっていれば
`http://<MacのIPアドレス>:8080` でスマホからアクセスできます(ホーム画面追加は使えません)。

## ファイル構成

- `index.html` — アプリ本体(画面構造)
- `style.css` — デザイン
- `nutrition.js` — 1日の必要栄養量の計算ロジック
- `storage.js` — 記録の保存(localStorage)
- `api.js` — Claude(Anthropic API)への写真解析リクエスト
- `app.js` — 画面の描画とイベント処理
- `manifest.json` / `sw.js` / `icon-*.png` — PWA(ホーム画面追加・オフライン対応)用

## 注意事項

本アプリが表示する1日の必要栄養量やAIによる栄養推定値は、一般的な目安・参考情報であり、
医学的なアドバイスではありません。妊娠・授乳中の方、成長期のお子様、持病のある方などは、
医師や管理栄養士にご相談のうえご利用ください。18歳以上の方を対象としています。
