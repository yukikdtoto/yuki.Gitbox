# 学習進捗トラッカー(Googleカレンダー連携)

Googleカレンダーの予定を「学習計画」として使い、実際に学習したかどうか・
どれくらい学習できたかを記録して、週の目標に対する進捗を可視化するアプリです。

- 学習の予定はGoogleカレンダーに書き込まれるので、普段使っているカレンダーアプリと同期されます。
- 「完了 / 一部 / 未実施」やメモなどの実績データは、この端末のブラウザ内(localStorage)にのみ保存され、外部には送信されません。
- Googleへのログイン情報(アクセストークン)はタブを閉じると失効し、次回開いたときは再ログインが必要です。
- サーバーは不要です。静的なHTML/CSS/JavaScriptだけで動きます。

## 1. Google Cloud ConsoleでOAuthクライアントIDを作る

1. https://console.cloud.google.com/ にアクセスし、プロジェクトを作成(または既存のものを選択)
2. 「APIとサービス」→「ライブラリ」から **Google Calendar API** を有効化
3. 「APIとサービス」→「OAuth同意画面」で、アプリの種類(外部/内部)を選び、必要な情報を入力
   - 公開前の「テスト中」の状態でも、自分のGoogleアカウントを「テストユーザー」に追加すれば動作します
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」
   - アプリケーションの種類: **ウェブ アプリケーション**
   - 「承認済みのJavaScript生成元」に、このアプリを開くURLを追加
     - ローカルで試す場合: `http://localhost:8080`
     - GitHub Pagesなどで公開する場合: `https://<あなたのドメイン>`
5. 発行された「クライアントID」(`xxxxxxxx.apps.googleusercontent.com` の形式)をコピー

APIキーは不要です。ログインしたユーザー自身のカレンダーにのみアクセスします。

## 2. 使い方

```bash
cd study-tracker
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開き、案内に従ってクライアントIDを入力してください。
初回は「Googleでログイン」からGoogleアカウントでの認証・カレンダーへのアクセス許可が必要です。

## 3. 学習予定として認識される条件

設定画面の「学習予定として扱うキーワード」(初期値: `勉強`)を含む予定だけを学習計画として
集計します。アプリ内の「予定を追加」から作成した予定には自動でこのキーワードが付きます。
キーワードを空欄にすると、選択したカレンダー内のすべての予定が対象になります。

複数の科目や予定と学習予定を分けたい場合は、Googleカレンダー側で専用のカレンダーを作成し、
設定画面の「対象カレンダー」でそのカレンダーを選ぶと管理しやすくなります。

## ファイル構成

- `index.html` — アプリ本体(画面構造)
- `style.css` — デザイン
- `storage.js` — 設定・実績記録の保存(localStorage)
- `calendar.js` — Google Identity Services / Calendar APIとの連携
- `app.js` — 画面の描画とイベント処理

## 注意事項

このアプリはGoogleが提供するID/APIクライアントライブラリを利用しています。
Googleアカウントへのアクセス許可は、あなたが発行したOAuthクライアントIDの
設定(承認済みのJavaScript生成元)を通した端末・URLからのみ有効です。
